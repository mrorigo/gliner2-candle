Architecture Highlights

Both GLiNER2 (span-enumeration) and GLiNER2.5 (boundary-prediction) pipelines run end-to-end in Rust, matching the Python reference numerically.

  • Custom DeBERTa-v3 encoder with relative position embeddings and sign-flipped rel_pos (matches HF)
  • GLiNER2: markerV0 span representation + classifier / count heads
  • GLiNER2.5: boundary encoder, shared-pool scorer with relation reranker, and span-attribute scoring
  • HF tokenizer-driven collator with schema + text batching, and auto-chunking for long documents (>384 words)
