Architecture

Two pipelines, one candle backend. From collation to thresholded extraction, every stage is explicit and debuggable.

  • Custom DeBERTa-v3 encoder — sign-corrected relative positions + exact-erf GELU
  • GLiNER2: markerV0 span rep + classifier / count heads
  • GLiNER2.5: boundary encoder + shared-pool scorer with relation reranker
  • Span attributes via hidden entity queries (score_explicit_spans) — no dedicated weights
  • Long documents auto-chunked (>384 words), merged with overlap policies

Pipeline

Text + schema flow through explicit, inspectable stages.
